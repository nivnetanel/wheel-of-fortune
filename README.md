# 🎡 גלגל המזל | Wheel of Fortune

אתר אינטראקטיבי בעברית (RTL) בעיצוב ניאון, שמסובב גלגל ובוחר זוכה אקראי מתוך רשימת משתתפים. לכל משתתף מוצגת תמונה בסיום הסיבוב.

**🔗 דמו חי:** https://nivnetanel.github.io/wheel-of-fortune/

## ✨ תכונות
- גלגל מזל מונפש עם אפקטי ניאון
- בחירת זוכה אקראית מתוך 30 משתתפים
- הצגת תמונת הזוכה בסיום הסיבוב
- תמיכה מלאה בעברית ובכיווניות RTL
- עמוד סטטי בקובץ יחיד — ללא תלויות חיצוניות

## 🚀 הרצה מקומית
פשוט פותחים את `index.html` בדפדפן. אין צורך בהתקנות או שרת.

## 📁 מבנה הפרויקט
```
index.html        עמוד הכניסה (מוגש על ידי GitHub Pages)
גלגל-המזל.html    עותק מקורי של העמוד
*.JPG             תמונות המשתתפים
.nojekyll         מונע עיבוד Jekyll של שמות קבצים בעברית
```

## 🛠️ טכנולוגיות
HTML · CSS · JavaScript (ללא ספריות חיצוניות)
